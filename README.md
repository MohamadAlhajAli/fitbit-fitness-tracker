# Fitbit Fitness Tracker Data



An exploratory data analysis project using Fitbit fitness tracker data.



## Objectives



- Understand the dataset's structure and collection methods.

- Assess missing values, duplicates, and data quality.

- Explore activity, sleep, and other available measurements.

- Document findings and limitations.



## Dataset



- Local data folder: `Dataset/`

- Original source: To be documented.

- Dataset license: To be verified.

- Collection period: To be documented.
